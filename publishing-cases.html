CASE 01

jQuery Mouseenter 이벤트를 활용한 대메뉴, 중메뉴 제어

PC사이즈 GNB 카테고리 메뉴 UI 및 스크롤 스타일 구현

  • SCSS를 활용한 카테고리 메뉴 레이아웃 구성
  • jQuery mouseenter 이벤트와 클래스 제어를 통한 하위 메뉴 표시
  • 카테고리별 활성·호버 상태 스타일링
  • overscroll-behavior 및 커스텀 스크롤바 스타일 적용

  • 문제상황CSS로만 구현시 대메뉴에 hover했을 때 중메뉴가 내부 스크롤에 가려져 보이지 않는 문제 발생
  • 해결방안대메뉴에 mouseenter 이벤트를 할당하여 absolute로 설정한 중메뉴를 계속 노출되도록 구현

CASE 02

jQuery Click, Scroll 이벤트를 활용한 카테고리 메뉴 제어

모바일 사이즈 GNB 카테고리 메뉴 UI 및 스크롤 스타일 구현

  • 스크롤 위치에 따른 대메뉴 활성 상태 동기화
  • 대메뉴 클릭 시 해당 중메뉴가 상단으로 스크롤되도록 구현
  • 활성 대메뉴가 항상 보이도록 대메뉴 목록 스크롤 처리
  • 요구사항대메뉴를 터치하면 매칭되는 중메뉴가 상단으로 스크롤되고, 중메뉴 영역을 스크롤하면 현재 위치에 맞는 대메뉴가 활성화되도록 구현
  • 문제상황스크롤 컨테이너 안에서 현재 보이는 중메뉴를 판단하고, 이를 대메뉴와 어떻게 매칭할지 정하는 부분이 어려웠음
  • 해결방안offset()으로 각 중메뉴의 상단 위치를 계산하고, 스크롤 컨테이너 상단과의 거리(30px)를 기준으로 현재 중메뉴를 판별해 대응하는 대메뉴를 활성화. 대메뉴 클릭 시에는 앞선 중메뉴들의 높이를 누적 계산해 해당 위치로 animate 스크롤

CASE 03

jQuery-UI.js의 코드를 분석하여 문제 해결

jQuery UI Datepicker의 a 태그를 button변경하여 SEO/접근성 이슈 개선

  • jQuery UI Datepicker 월 이동 버튼 마크업 개선
  • 기능 목적에 맞는 시맨틱 태그 적용
  • 기존 월 이동 동작을 유지한 접근성·SEO 개선
  • 요구사항SEO·접근성 평가 과정에서 지적된 Datepicker 월 이동 요소의 마크업을 기능 목적에 맞게 개선
  • 문제상황페이지 이동 기능이 없는 월 이전·다음 요소가 a 태그로 생성되고 있었으며 해당 요소는 jQuery UI 내부에서 동적으로 만들어지는 구조여서, 화면 마크업만 수정해서는 해결할 수 없었음.
  • 해결방안jQuery UI 라이브러리 파일에서 Datepicker 요소를 생성하는 코드를 분석, 월 이동 요소의 a 태그를 button으로 변경하고, 기존 클래스와 이벤트 동작은 유지하도록 수정 이를 통해 기능 목적에 맞는 시맨틱 마크업으로 개선.
